# Java Backend Portfolio

Colección de proyectos y ejercicios desarrollados durante mi formación en Backend Java.

## Contenido

El repositorio reúne prácticas relacionadas con:

- Programación orientada a objetos.
- JDBC y MySQL.
- Bases de datos SQL y MongoDB.
- JUnit.
- Gradle.
- Patrones de diseño.
- Spring Boot.
- Persistencia.
- Desarrollo de aplicaciones Java.

Entre los proyectos incluidos se encuentran ejercicios de biblioteca con JDBC, consultas SQL, patrones de diseño y testing.

## Tecnologías

- Java
- JDBC
- MySQL
- MongoDB
- JUnit
- Gradle
- Spring Boot
- SQL

## Uso

Cada directorio corresponde a un ejercicio o módulo independiente. Consulta su estructura y archivos para ejecutar el proyecto correspondiente.
