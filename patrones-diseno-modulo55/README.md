# Patrones de Diseno - Modulo 55

Proyecto Java con implementaciones practicas de patrones de diseno estructurales y de comportamiento.

## Patrones implementados

### Decorator
Extiende el comportamiento de un objeto Coffee mediante MilkDecorator.

### Observer
NotificationService administra observadores y distribuye notificaciones a objetos suscritos.

### State
Order modifica su comportamiento utilizando estados como PendingState y ShippedState.

### Proxy
InternetProxy controla el acceso a una implementacion de Internet y permite restringir determinados sitios.

## Tecnologias

- Java 11
- Gradle
- Programacion orientada a objetos
- Patrones de diseno
