# Fundamentos de Bases de Datos

Ejercicio práctico de bases de datos relacionales desarrollado durante la formación Backend Java de EBAC.

## Contenido

El proyecto utiliza una base de datos de ejemplo para una tienda con las entidades clientes, productos y pedidos.

Incluye ejercicios de:

- DDL: creación de base de datos y tablas.
- Claves primarias y foráneas.
- ALTER TABLE.
- DML: INSERT, UPDATE y DELETE.
- DQL: SELECT, filtros y ordenamiento.
- INNER JOIN entre clientes, productos y pedidos.
- DCL: creación de usuarios, GRANT y REVOKE.

## Tecnologías

- SQL
- MySQL
- Modelo relacional
