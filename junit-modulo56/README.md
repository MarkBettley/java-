# Testing con JUnit 5 - Modulo 56

Proyecto Java enfocado en pruebas unitarias desarrollado durante la formacion Backend Java de EBAC.

## Funcionalidad

Implementa una calculadora con operaciones de suma, resta, multiplicacion y division, incluyendo manejo de division entre cero.

## Testing

CalculatorTest contiene cinco pruebas automatizadas para validar las operaciones matematicas y el comportamiento ante una division entre cero.

## Tecnologias

- Java 11
- Gradle
- JUnit 5

## Ejecutar pruebas

    ./gradlew test

## Ejecutar aplicacion

    ./gradlew run
