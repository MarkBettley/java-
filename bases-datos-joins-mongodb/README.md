# SQL JOINs y MongoDB

Ejercicios de bases de datos relacionales y documentales desarrollados durante la formación Backend Java de EBAC.

## SQL

El proyecto modela usuarios, teléfonos y direcciones mediante relaciones y claves foráneas.

Se implementan:

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Simulación de FULL OUTER JOIN mediante UNION
- Creación de tablas y relaciones
- Inserción de datos

Archivo: `consultas-sql.sql`

## MongoDB

Incluye un ejercicio documental con colecciones de usuarios y productos.

Se practican:

- Creación de colecciones
- Inserción de documentos
- Consultas con find
- Filtros
- Operadores de comparación
- Eliminación de documentos

Archivo: `consultas-mongodb.js`

## Tecnologías

- SQL
- MySQL
- MongoDB
