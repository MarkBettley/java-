# Patrones de Diseno - Modulo 54

Proyecto Java dedicado a la implementacion practica de patrones de diseno creacionales.

## Patrones implementados

### Singleton

AppConfiguration mantiene una unica instancia de configuracion de la aplicacion.

### Factory

NotificationFactory crea diferentes implementaciones de Notification, incluyendo correo electronico y SMS.

### Builder

UserProfile.Builder permite construir objetos UserProfile configurando sus atributos mediante una API fluida.

## Tecnologias

- Java 11
- Gradle
- Programacion orientada a objetos
- Patrones de diseno

## Ejecutar

    ./gradlew run
